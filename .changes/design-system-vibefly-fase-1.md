A aparência do produto muda (cores, tipografia, raios e sombras), mas nenhuma
tela, rota, permissão ou fluxo existente sai do lugar — é troca de pele, não
de esqueleto. Accent passa de verde Sage para tinta escura (`#2c2920`); o CTA
lime do design importado existe como variante nova de botão (`spark`), ainda
não aplicada a nenhuma tela. Fontes: Outfit nos títulos, Inter no corpo,
JetBrains Mono nos valores tabulares. Quem já instalou não precisa editar
nada — é CSS e fonte, sem migration, sem env nova. Fase 2 (aplicar aos
componentes/telas principais) fica para um PR seguinte.
